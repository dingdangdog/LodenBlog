# 专栏可以删除

## 目的

创作者专栏列表以前只能新建和编辑。删除专栏时需要明确文章去留：留下的改为单篇付费，一起删除的不能从站点消失后却被物理清掉。

## 变更

- 专栏列表增加删除。确认时选择保留文章或连同文章删除。
- 专栏改为 `status = DELETED` 并取消发布，公开地址让出。未使用的专栏兑换码作废，订阅记录保留。
- 保留文章时，专栏文章改为 `PAID` 并脱离专栏，价格保持原样。
- 连同删除时，文章同样标记 `DELETED`、取消发布并让出地址；未使用的文章兑换码作废。正文、解锁和订阅记录仍留在库里。
- 已删除专栏在「我的订阅」里保留名称，但不再链到专栏页。

## 影响范围

- 创作者专栏列表、专栏文章、文章列表、公开专栏、搜索、站点地图、作者页、订阅与解锁
- `prisma/schema.prisma` 只补充了状态注释

## 数据库

没有新增字段，也没有生成 migration。`columns.status` 和 `article_bases.status` 本来就是字符串，现在允许 `DELETED`。

## 验证

- `node --experimental-strip-types --test utils/column-access.test.ts`：18 项通过。
- 本地开发服务无法连接数据库，专栏页请求返回 302 登录跳转。没有在浏览器里完成删除点击。
