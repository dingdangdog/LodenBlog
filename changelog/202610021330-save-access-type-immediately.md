# 切换访问类型后立即保存

**日期：** 2026-10-02

## 背景 / 问题

访问类型只改了编辑页上的选项，数据库仍是免费。这时生成兑换码会返回「只有单篇付费文章可以生成解锁码」。

## 变更内容

- 切换访问类型后立即调用现有的「只保存」流程，把类型写入文章。
- 选成专栏但还没选专栏时先不保存；选定专栏后再保存。
- 保存成功前不显示兑换码区域，避免用旧的免费状态去生成。

## 影响范围

- `app/pages/admin/editpost.client.vue`

## 数据库与兼容性

- 无表结构变化。保存仍走原有文章更新接口。

## 验证

- 对照保存请求体里的 `accessType` 与兑换码接口的判断。
- 浏览器未点击验证。
