# 免费分界提示与编辑器插入按钮

**日期：** 2026-10-02

## 背景 / 问题

免费分界说明放在阅读权限区，正文编辑时看不到。插入 `<!--free-->` 也要离开编辑器去点按钮，而且会额外换行。

## 变更内容

- 提示改为「`<!--free-->`之前的内容可以免费阅读」，放在正文选项卡编辑器底部、字数统计右侧。
- 文章编辑器工具栏增加「插入免费分界」。点击后在当前光标处插入 `<!--free-->`，不附加换行。
- 阅读权限区不再保留原来的插入按钮和那段说明。信息页编辑器不显示该按钮。

## 影响范围

- `app/components/editor/MarkdownEditor.client.vue`
- `app/pages/admin/editpost.client.vue`
- `locales/*/admin/editpost.json`

## 数据库与兼容性

- 无数据库影响。仍只按第一次 `<!--free-->` 切分免费段。

## 验证

- 对照现有 `md-editor-v3` 自定义工具栏写法接入按钮。
- 浏览器点击插入：未测试。
