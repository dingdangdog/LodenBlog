# 管理端文章最小字数调整记录

## 变更时间

2026-04-14

## 变更内容

1. 将管理端文章编辑页 `app/pages/admin/editpost.client.vue` 中的正文最小字数限制从 `1000` 调整为 `300`。
2. 保留现有的最大字数限制 `50000` 不变。
3. 同步检查了后端文章创建接口 `server/api/creator/articles/index.post.ts` 和更新接口 `server/api/creator/articles/[id].patch.ts`，当前未发现正文最小字数为 `1000` 的服务端限制，因此无需额外修改后端逻辑。

## 影响范围

1. 管理端新建文章时，正文达到 `300` 字即可保存或发布。
2. 管理端编辑文章时，正文达到 `300` 字即可保存或发布。
3. 前端校验提示中的最小字数会随常量自动显示为 `300`。
